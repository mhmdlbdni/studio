# **App Name**: Executive Vision

## Core Features:

- Dashboard: Presents an overview of the user's financial status with total income, expenses, and net balance displayed in summary cards.
- Transaction Tracking: Enables users to record income and expenses, assigning them to specific budget categories (مثل الضروريات, الحرية المالية, الخ).
- AI Financial Guide: Offers users financial advice, suggests saving strategies, and helps users to achieve better financial balance.
- Budget Customization: Lets users adjust the percentage allocated to each 'pot' (وعاء), and shows a visual indicator of whether the total allocation equals 100%.
- Settings: Settings Screen: To control appearance (themes and colors), currency, language, and to manage user accounts.
- Category Details: Display transaction history of each category in an interactive format.

## Style Guidelines:

- Dark Mode background color: #121212 (very dark gray)
- Card background color: #1E1E1E (a slightly lighter dark gray)
- Primary interaction color: #47abff (a light, vibrant blue, contrasting against the dark background)
- Font choice: 'Tajawal' sans-serif for headlines and body, as requested by the user. Note: currently only Google Fonts are supported.
- Headlines (H1): 'Tajawal Bold', 24px
- Sub-headlines (H2): 'Tajawal Medium', 18px
- Body copy: 'Tajawal Regular', 16px
- Minimalist icons representing each 'pot', providing clear visual cues to the user.
